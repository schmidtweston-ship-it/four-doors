# Four Doors

A phone-first walk. Not a treatment. Not medical. Not 12-step. A mixture. The person chooses.

In the moment: **Where are you. Where do you want to go. Which door can you walk through today.**

## The four doors

1. **Meet me first** — match sound and color to here, briefly, then walk toward there. Do not linger.
2. **Take me there** — destination now. When you need out. You can bail to door 1.
3. **Lock to my body** — tap breath or pulse. Color moves with you. Tempo walks toward there. Respects reduced motion.
4. **Walk with [name]** — the weight of the product. A named partner (default **Partner**) and a four-count: one, two, three, four. Visual numbers, optional spoken numbers, optional recorded voice, a tonal pulse. Tap a beat, then hold. Talk can attune and lead; the count is the spine when words fail.

Color is a layer on every door, not a fifth door.

## What this is not

Not a clinic. Not a therapist. Not a crisis product. No account. Setup lives in `localStorage` on the phone. Incomplete setup still works with defaults.

## Open locally

Any static server from this folder:

```
python3 -m http.server 8080
```

Then open `http://localhost:8080/` on a phone or in a browser. Sound needs a tap (browser rule).
